# Multi-router swap quotes pick the best expected net out

**Date:** 7 September 2026

Protocol **1.7.1**. `POST /swaps/quote` quotes every enabled swap router in parallel and returns the **best expected net out**. Compose, plans, and rebalance use the same compare. Canix still never holds keys or submits transactions.

## What shipped

### Parallel multi-router compare

Enabled adapters quote at the same time. The winner is the only route compiled into opt-in and swap groups. Other adapters land in `alternatives[]` as `quoted`, `error`, `skipped`, or `timeout`.

Routers in this compare:

| `router` | What it is |
| --- | --- |
| `haystack` | Existing Haystack aggregator |
| `hogswap` | LiquiHog HOGSWAP multi-DEX aggregator |
| `tinyman` | Tinyman Swap Router (Tinyman pools only, not a cross-DEX aggregator) |
| `pact-smart-router` | Pact Smart Router |
| `folks-router` | Folks Router V2 (`@folks-router/js-sdk`; no public Folks HTTP) |
| `asastats` | ASA Stats Smart Router (quoted only when `ASASTATS_API_TOKEN` is set) |

Omit `router` to compare all enabled adapters. Pass `router` to force one. Default slippage is **1%**. Each adapter has an **8s** quote timeout (`META_SWAP_QUOTE_TIMEOUT_MS`). Quotes still live ~30s.

### Best price is the winner

Scoring is expected net return, not first-to-answer:

- **Fixed-input:** higher `expectedNetOut`, then higher `minOut`, then lower network fee, then a stable priority list (Haystack first).
- **Fixed-output:** lower `expectedIn`, then lower `maxIn`, then lower network fee, then the same priority list.

`quotedAmount` on the response is the winner’s expected net out. `score` and `alternatives[]` are there so agents can audit why that router won. `payload` is opaque winner state — **do not edit it**. Pass the quote object unchanged into `POST /swaps/optin` and `POST /swaps/transactions`.

### Compose, plans, and rebalance

`POST /execution/compose`, `POST /plans`, and `POST /plans/rebalance` compile the same winning swap. Shape keys stay `mainnet:swap:router:optin:required` and `mainnet:swap:router:swap:fixed-input`; the winning adapter is `metadata.router`. Preserve signer indexes and any pre-signed members from that router. Groups stay unmerged.

MCP: `canix_get_quote` / `canix_optin` / `canix_swap` use the same contract. Docs: `protocol/docs/execution-shapes/haystack-swap-compose.md`, plus the per-router sources under `protocol/docs/data-sources/`.

### Quote shape (breaking for Haystack-only clients)

`POST /swaps/quote` now returns a **meta** quote (`router`, `score`, `alternatives`, `legs`, `payload`), not a Haystack-only object (`txnPayload`, `requiredAppOptIns`, `protocolFees`, …). Strict clients that parsed the old Haystack fields must accept the new shape and pass `data` through unchanged. Opt-in and swap transaction requests take that meta quote, not a Haystack payload.

ASA Stats stays skipped until a partner token with `router:quote` / `router:group` is configured. Folks Router is an internal compare source only — there are no `/swaps/folks/*` routes.

### Quality

Fixture-based unit coverage for winner selection, timeouts, and pinned-router vs all-enabled compare (`protocol/tests/unit/meta-swap-router.test.ts`). Per-adapter quote/execute fixtures for HOGSWAP, Tinyman Swap Router, Pact Smart Router, Folks Router V2, and ASA Stats remain in `protocol/tests/unit/` and `protocol/tests/integration/`. Safe-batch dependency hoist includes AlgoKit Utils **9.2.2** so TypeScript sees a single copy.

## Pricing

No new SKUs.

| Step | Route / tool | Price |
| --- | --- | --- |
| Multi-router quote | `POST /swaps/quote` / `canix_get_quote` | **free** |
| Prerequisite opt-ins | `POST /swaps/optin` / `canix_optin` | **free** |
| Swap group from the winning quote | `POST /swaps/transactions` / `canix_swap` | **0.005 USDC** |
| Swap-aware compose | `POST /execution/compose` / `canix_compose_enter` | **0.10 USDC** |
| Plan / rebalance (includes compose) | `POST /plans`, `POST /plans/rebalance` | **0.25 USDC** |

The 0.005 USDC x402 access charge is separate from router fees, DEX fees, price impact, and Algorand network fees. No new Caddy `X402_PRICE_*` variables. Optional protocol env: `META_SWAP_QUOTE_TIMEOUT_MS` (default 8000), plus the existing per-router knobs in `protocol/.env.example` (`HAYSTACK_*`, `HOGSWAP_*`, `FOLKS_ROUTER_*`, `PACT_SMART_ROUTER_APP_ID`, `ASASTATS_*`).

## Agent loop

1. `POST /swaps/quote` / `canix_get_quote` with `address`, `fromAssetId`, `toAssetId`, `amount`. Omit `router` unless you must pin one adapter. Read `data.router` and `data.alternatives` before signing.
2. Optional `POST /swaps/optin` / `canix_optin` with the quote unchanged. Submit the opt-in group and wait for confirmation, then **re-quote** — the previous swap quote is likely stale.
3. `POST /swaps/transactions` / `canix_swap` (or compose / plan) with the fresh winning quote. Sign only `userSignIndexes` / `signer: "user"` legs. Preserve pre-signed members. Submit locally before `expiresAt`. Never merge groups.
4. For “I hold A, I want this opportunity,” use `POST /execution/compose` / `canix_compose_enter` instead of stitching quote + enter yourself. Canix never holds keys.
