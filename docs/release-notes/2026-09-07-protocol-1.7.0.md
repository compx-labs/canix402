# STAMM LP discovery, unsigned mint/redeem, and HOGSWAP LP positions

**Date:** 7 September 2026

Protocol **1.7.0**. Agents can list LiquiHog STAMM fee-tier LP opportunities, value STAMM / AlgoFi / Humble LP holdings through HOGSWAP, and compile unsigned mint or redeem groups. Canix still never holds keys or submits transactions.

## What shipped

### STAMM LP opportunities

`stamm` is a first-class opportunity protocol. Discovery is HOGSWAP HTTP (`GET /stamm/pools`), not `stamm-py-sdk`. One public row per **active fee tier**, not per pool. `opportunityId` is `{pool_id}:lp:{tier_index}` so holdings join the same row.

Listings expose **TVL and fee bps**. `apy` is `0` (unknown). Do not invent fee-APR from incomplete volume. Opportunity history does not snapshot these rows. See `protocol/docs/data-sources/stamm.md`.

`GET /protocols/stamm/opportunities` and `platform=stamm` search work. AlgoFi and Humble stay **positions-only** — they are not opportunity catalog slugs.

### Unsigned STAMM mint / redeem

Execution shapes:

- `mainnet:stamm:v1:mint:lp` — pool assets (`amountA` / `amountB`, one side may be `0`) or `externalInputs` (any routable asset converted into the tier ratio)
- `mainnet:stamm:v1:redeem:lp` — burn `lpAmount` to a pool asset or any `targetAsset`

Flow matches Haystack compose: HOGSWAP `POST /quote` then `POST /execute`. Canix returns unsigned groups and never broadcasts. Quotes live ~30s. The wallet must already be opted into the LP ASA before execute. **Do not hardcode router or registry app ids** — `/execute` always targets the live router.

Optional `maxLegs` (1–16) is forwarded when composing with other groups. Docs: `protocol/docs/execution-shapes/stamm-mint-lp.md`, `stamm-redeem-lp.md`.

### Unified HOGSWAP LP positions

`GET /positions` values LP ASAs that HOGSWAP indexes for STAMM, AlgoFi, and Humble via `GET /lp/{asset_id}?amount=`. USD is a **proportional-share NAV** of pool reserves at HOGSWAP analytics prices — no slippage, no exit fee, not executable redeem proceeds. Missing supply or reserve prices stay `null`; Canix does not invent USD.

Tinyman and Pact LP collectors remain canonical. HOGSWAP skips those DEX names so LP ASAs are not double-counted. See `protocol/docs/data-sources/hogswap-lp.md`.

### Quality

Fixture-based unit and API coverage for HOGSWAP LP normalize/positions and STAMM catalog/mint/redeem. HOGSWAP HTTP now times out hung quote, execute, and catalog fetches (`HOGSWAP_HTTP_TIMEOUT_MS`, default 8s).

## Agent loop

1. `GET /protocols/stamm/opportunities` / `canix_get_protocol_opportunities` with `protocol=stamm`. Read TVL, fee bps, and `inputHints` (`poolAppId`, `tierIndex`, LP ASA). Treat `apy: 0` as unknown, not zero yield.
2. Optional `GET /positions` / `canix_get_positions` for STAMM / AlgoFi / Humble LP NAV. Null USD means missing HOGSWAP pricing, not zero.
3. `POST /execution/quotes` / `canix_get_execution_quote` with `mainnet:stamm:v1:mint:lp` or `mainnet:stamm:v1:redeem:lp`. Confirm LP ASA opt-in before execute.
4. Sign only user legs. Submit locally before the HOGSWAP quote expires. Canix never holds keys.
