# Morpho Vaults on Base and mixed-chain opportunity catalog

**Date:** 21 September 2026

Protocol **1.8.0**. The first non-Algorand venue is listed Morpho Vaults on Base. Default `GET /opportunities` mixes Algorand rows with those Base vaults. Every public row now carries `chain`. x402 payment stays Algorand USDC. Canix still never holds keys or submits transactions.

## What shipped

### Mixed-chain catalog

Public opportunity rows require `chain`: `algorand` or `base`. Filter with `chain=` on list and search. Morpho is a first-class protocol slug (`GET /protocols/morpho/opportunities`, `protocol=morpho`). Adapter isolation is unchanged — a Morpho GraphQL timeout does not fail the rest of the catalog.

ERC-20 underlyings use `assetAddresses`. Do not put `0x` values into integer `assetIds`. The vault address is `inputHints.poolId`.

`GET /positions` and `/opportunities/personalized` stay Algorand. Morpho holdings are not collected in this release.

### Morpho Vaults (Base, supply-only)

Discovery is Morpho GraphQL (`https://api.morpho.org/graphql`), `chainId` 8453, `listed: true` by default (`MORPHO_ONLY_LISTED`). `netApy` is a fraction; Canix publishes it as percent. Native ETH underlyings, zero TVL, and missing `netApy` are dropped.

See `protocol/docs/data-sources/morpho.md`.

### Unsigned ERC-4626 quotes

Execution shapes:

- `base:morpho:vault:deposit:erc4626` — optional ERC-20 `approve`, then `deposit(assets, receiver)`
- `base:morpho:vault:withdraw:erc4626`
- `base:morpho:vault:redeem:erc4626`

Quotes are unsigned Base calldata. `identity.network` is `base`. `encodedTransactions` are hex. Structured `{ to, data, value, chainId }` is on `transactions[].evmCall` and `metadata.evmCalls`. Permit2, Bundler3, Morpho Blue borrow, Public Allocator, and Vault V2 force-withdraw are out of scope.

Docs: `protocol/docs/execution-shapes/morpho-deposit-erc4626.md`, `morpho-withdraw-erc4626.md`, `morpho-redeem-erc4626.md`.

### Quality

Fixture-based unit and API coverage for vault normalize and ERC-4626 compile (`protocol/tests/unit/morpho-*.test.ts`, `protocol/tests/integration/morpho-execution-shapes.test.ts`). Live GraphQL/RPC is not required for CI.

## Pricing

No new SKUs. Merchant rail remains Algorand USDC.

| Step | Route / tool | Price |
| --- | --- | --- |
| Morpho / mixed catalog | `GET /opportunities*`, `GET /protocols/morpho/opportunities` | **0.01 USDC** (existing catalog) |
| Morpho deposit / withdraw / redeem compile | `POST /execution/quotes` / `canix_get_execution_quote` | **0.10 USDC** flat per request |

No new Caddy `X402_PRICE_*` variables. Optional protocol env: `MORPHO_GRAPHQL_URL` (default `https://api.morpho.org/graphql`), `MORPHO_ONLY_LISTED` (default `true`), `BASE_RPC_URL` (quotes only; default `https://mainnet.base.org`).

## Agent loop

1. `GET /opportunities?protocol=morpho` or `GET /protocols/morpho/opportunities` / `canix_get_protocol_opportunities`. Read `chain: "base"`, `assetAddresses`, and `inputHints.poolId` (vault). Use `chain=algorand` when you only want Algorand rows.
2. `POST /execution/quotes` / `canix_get_execution_quote` with `base:morpho:vault:deposit:erc4626` (or withdraw / redeem). Pass a Base `0x` `userAddress` and the vault from `inputHints.poolId`. Amount is underlying ERC-20 base units.
3. Sign the returned calldata on Base (`metadata.evmCalls`). Submit locally. Canix never holds EVM keys and does not broadcast.
4. Pay the x402 access charge with Algorand USDC as before. Paying for a quote does not execute the quote.
