# Prepaid sessions, delta rebalance, and expected-delta simulation

**Date:** 27 August 2026

Protocol **1.6.0**. Since 1.4.0, agents can buy one prepaid session instead of spraying tiny USDC one-shots, compile a **delta** against the current book, and dry-run unsigned groups before signing. Canix still never holds keys or submits transactions.

## What shipped

### Prepaid agent sessions

Exact-scheme per-request x402 stays the default. Operators who would otherwise spray research and quote micropayments can mint a walletless receipt instead: one compiler-priced payment unlocks **N research** calls and **M quotes/plans** for a TTL.

- `POST /sessions` (0.25 USDC) mints `canix://session/{sessionId}` (`csess_` + 32-byte hex). Defaults: **50** research, **10** quotes/plans, **4 hour** TTL.
- `POST /sessions/refresh` is also one-shot x402. It resets N/M and TTL in place, or mints a new receipt. Create/refresh **cannot** be paid with a session header.
- `GET /sessions/:sessionId` is free and returns remaining N/M. Unknown or Redis-evicted ids fail-closed `402 SESSION_INVALID`. Expired records still readable fail-closed `402 SESSION_EXPIRED`. Store down is `402 SESSION_UNAVAILABLE` (create returns `503`). Exhausted-but-unexpired is `200` with `status: "exhausted"`.

Caddy skips x402 only when `X-Canix-Session` starts with `csess_` on a session-eligible path. Empty or whitespace headers stay on the payment path. The protocol process then consumes one unit from the matching bucket and fail-closes. Successful consumes attach `x-canix-session-remaining-research`, `x-canix-session-remaining-quotes`, and `x-canix-session-expires-at`.

**Research (N):** `/opportunities`, `/opportunities/search`, `/opportunities/personalized`, `/protocols/:protocol/opportunities`, `/positions`, `/positions/claimable`, `/eligibility`.

**Quotes (M):** `/plans`, `/plans/rebalance`, `/execution/quotes`, `/execution/compose`, `/execution/simulate`, `/swaps/transactions`.

Sessions are receipts, not keys. Production without `REDIS_URL` fail-closes. MCP: `canix_create_session`, `canix_refresh_session`, `canix_get_session`; eligible paid tools accept `sessionReceipt`. Policy is `canix://session`; remaining N/M is `canix://session/{sessionId}`. If `paymentSignature` is set, MCP omits the session header so a stale receipt cannot swallow a paid retry. See `protocol/docs/agent-sessions.md`.

To fall back to a one-shot after `SESSION_EXPIRED` / `SESSION_EXHAUSTED` / `SESSION_INVALID`, **omit the header** and retry with `PAYMENT-SIGNATURE`.

### Paid `POST /plans/rebalance`

New compiler SKU: `{ address, targetWeights?, harvestIdle?, includeClaims?, algoReserveMicroAlgos?, minDeltaBps?, constraints?, swapSlippage? }`. Provide target weights (bps summing to 10000) and/or `harvestIdle: true`. This is a delta against the current book — not a full unwind-and-rebuild.

- Positions not listed in `targetWeights` are left unchanged.
- Overweight rows emit a **partial** exit using `compatibleExitShapeKeys` (full exit only when target weight is 0).
- `harvestIdle` claims worth-claiming reward rows from the claim desk and redeploys wallet ALGO above a 1 ALGO reserve (configurable).
- Enters reuse eligibility + swap-aware compose. Enter that would spend unconfirmed exit proceeds is `compileStatus: deferred`.
- Ordered unsigned groups: claims → exits → opt-in/swap/enter. `meta.groupsMerged` is always `false`.

MCP: `canix_get_rebalance_plan`. See `protocol/docs/execution-shapes/rebalance-delta.md`.

### Paid `POST /execution/simulate`

Compiler SKU: `{ address, groups[] }`. Pass compiled quotes from `POST /execution/quotes`, `POST /execution/compose`, `POST /plans`, or `POST /plans/rebalance`.

- Predicted ALGO/ASA `balanceDeltas` and `expectedPositionDelta`. `wouldSucceed` is true only when every group is proven safe.
- Fail closed with machine-readable `reasons[].code`: `stale-quote`, `not-opted-in`, `min-balance`, `health-factor-too-low`, `capacity`, plus `insufficient-balance`, `malformed-group`, `holdings-unavailable`.
- `data.signed`, `data.submitted`, `meta.signed`, and `meta.executionSubmitted` are always `false`.
- `POST /plans` and `POST /plans/rebalance` attach the same summary as `data.simulation` when compiled groups exist. Paying for the plan does not execute it.

Health-factor fail-closed is a threshold check (`<= 1` or missing HF on borrow groups), not a full post-borrow model. MCP: `canix_simulate_execution`. See `protocol/docs/execution-shapes/simulate-expected-delta.md`.

### Quality

Fixture-based `protocol/tests/unit/` coverage for the remaining adapters: Myth Finance (dualSTAKE + farm), Haystack HAY staking, Réti per-validator consensus, and Alpha Arcade trailing 7d fee-share. Enter/exit shape attachment for those four is asserted without live chain or x402.

Safe-batch dependency upgrades include Fastify **5.12.1** (schema validation bypass and `trustProxy` hop-count spoofing; this repo does not set `trustProxy`), MCP SDK 1.30.0 on the Worker v1 line, and in-range `tsx` / TypeBox / Wrangler bumps.

## Agent loop

1. Optional `POST /sessions` / `canix_create_session`. Pass `X-Canix-Session` / `sessionReceipt` on research and quote calls for the TTL.
2. Optional `GET /positions` / `GET /positions/claimable`. Then `POST /plans/rebalance` / `canix_get_rebalance_plan` (delta) or `POST /plans` / `canix_get_plan` (allocation).
3. Review `data.simulation` on the plan, or call `POST /execution/simulate` / `canix_simulate_execution`. If `wouldSucceed` is false, do not sign — publish `reasons[]`.
4. Review `blocked[]`, step warnings, and `meta.groupsMerged === false`. Sign only user legs. Submit each group separately in `order` before `expiresAt`. Never merge groups.
5. On `SESSION_EXPIRED` / `SESSION_EXHAUSTED` / `SESSION_INVALID`, omit the session header and either refresh (`POST /sessions/refresh`) or pay per request.
