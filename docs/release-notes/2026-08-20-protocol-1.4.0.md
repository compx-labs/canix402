# Swap-aware enter compose and execution caveats

**Date:** 20 August 2026

Protocol **1.4.0**. Agents that already hold a budget asset can now compile a live Haystack path into an enter, instead of stitching opt-in, swap, and quote calls themselves. Construction caveats for Tinyman, Folks Finance, Pact, CompX, and Dork.fi are published so agents do not invent pool IDs, opt-ins, or slippage. Canix still never holds keys or submits transactions.

## What shipped

### Paid `POST /execution/compose`

New compiler SKU for a single opportunity: `{ address, opportunityId, fromAssetId, amount, slippage? }`. Canix returns ordered unsigned steps — optional ASA/app opt-in, live Haystack swap, then enter — driven by the opportunity’s unique `requiredAssetIds`.

Groups stay unmerged. Haystack signer indexes and pre-signed members are preserved (`signer: "logicsig"` + `signedTransaction`). Sign only `userSignIndexes` / `signer: "user"` legs and submit locally in `order`. Two-sided LP (more than one required asset) is not auto-composed.

Default Haystack slippage is 1%. Stale-quote, missing-opt-in, and slippage warnings are attached to the relevant steps. See `protocol/docs/execution-shapes/haystack-swap-compose.md`. MCP: `canix_compose_enter`.

### `POST /plans` now composes live swaps

The existing 0.25 USDC plan compiler no longer returns swap **hints**. When the budget asset is not the unique enter asset, `POST /plans` / `canix_get_plan` compiles the same opt-in → Haystack swap → enter graph (optional `swapSlippage`). Folks-style setup that needs a confirmed escrow stays `compileStatus: deferred` for a later `POST /execution/quotes`.

Agents that previously treated plan swap steps as informational must now treat them as executable unsigned groups with the same signer rules as compose.

### Execution caveats hub

`protocol/docs/execution-shapes/protocol-caveats.md` covers pool discovery, opt-ins, min-balance, slippage math, liquidity limits, and app-upgrade tripwires for Tinyman, Folks Finance, Pact, CompX, and Dork.fi. `GET /execution/shapes` exposes it as `meta.caveatsDocsPath`. OpenAPI, discovery, and MCP `canix_list_execution_shapes` / `canix_get_execution_quote` point at it.

### Quality

Fixture-based `protocol/tests/unit/` coverage for Tinyman, Folks, Pact, CompX, and Dork.fi opportunity normalization (no live chain, no x402). CI runs `test:unit` before API tests.

## Agent loop

1. Optional `GET /opportunities/personalized` / `canix_get_personalized_opportunities`
2. For one opportunity: `POST /execution/compose` / `canix_compose_enter`. For a budget allocation: `POST /plans` / `canix_get_plan`
3. Review `blocked[]`, step warnings, and `meta.caveatsDocsPath` before signing
4. Sign only user legs. Submit opt-in, then swap, then enter locally before `expiresAt` (Haystack quotes are typically ~30s). Never merge groups.
5. If opt-in confirmation ages the swap quote, re-call compose (or `POST /swaps/quote` → `POST /swaps/transactions`, then `POST /execution/quotes` for enter)
