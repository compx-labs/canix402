# Swap-aware enter compose

**Date:** 19 August 2026

Compose “I hold asset A, I want this opportunity” into sequenced unsigned groups: opt-in → Haystack swap → enter, driven by `requiredAssetIds`. Groups stay unmerged; Haystack signer indexes and pre-signed members are preserved. The caller signs user legs and submits locally.

## What shipped

- Paid `POST /execution/compose` accepts `{ address, opportunityId, fromAssetId, amount, slippage? }` (~0.10 USDC) and returns ordered steps with live Haystack opt-in/swap groups plus enter quotes.
- `POST /plans` / `canix_get_plan` now compose the same graph when the budget asset is not the unique `requiredAssetIds` target (optional `swapSlippage`).
- Caveats for stale quote, missing opt-in, and slippage are attached to swap/opt-in/enter steps. See `protocol/docs/execution-shapes/haystack-swap-compose.md`.

MCP: `canix_compose_enter`. Agent loop: eligibility or plan → review warnings → sign only user legs → submit opt-in, then swap, then enter before expiry.
