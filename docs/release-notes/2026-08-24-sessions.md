# Prepaid agent sessions

**Date:** 24 August 2026

Checklist 13.8. Exact-scheme one-shot x402 payments remain the default. Operators
who would otherwise spray tiny USDC transfers can buy one prepaid session instead.

## What shipped

- `POST /sessions` and `POST /sessions/refresh` (compiler-priced, default 0.25 USDC)
  mint or reset a walletless receipt: N research calls + M quotes/plans for a TTL.
- `GET /sessions/:sessionId` is free and returns remaining N/M. Unknown/expired
  receipts fail-closed with `402 SESSION_*`.
- Caddy skips x402 when `X-Canix-Session` starts with `csess_` on session-eligible routes;
  empty/whitespace headers do not skip payment. The protocol process consumes quota
  and fail-closes. Create/refresh stay one-shot.
- Discovery, OpenAPI, MCP tools (`canix_create_session`, `canix_refresh_session`,
  `canix_get_session`), policy resource `canix://session`, and receipt resource
  `canix://session/{sessionId}` publish the contract to agents.
  Session-eligible paid tools accept `sessionReceipt`.
- Redis (`canix402:session:{id}`) when `REDIS_URL` is set; production without Redis
  fail-closes. Sessions are receipts, not keys.

See `protocol/docs/agent-sessions.md`.
