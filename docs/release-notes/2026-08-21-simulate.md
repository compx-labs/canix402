# Simulate / expected delta

**Date:** 21 August 2026

Protocol **1.6.0**. Agents can dry-run compiled unsigned groups and get predicted
balance and position deltas before signing. Canix still never holds keys or
submits transactions.

## What shipped

### Paid `POST /execution/simulate`

Compiler SKU: `{ address, groups[] }`. Pass compiled quotes from
`POST /execution/quotes`, `POST /plans`, or `POST /plans/rebalance`.

- Predicted ALGO/ASA `balanceDeltas` and `expectedPositionDelta`
- Fail closed with machine-readable `reasons[].code` (`stale-quote`,
  `not-opted-in`, `min-balance`, `health-factor-too-low`, `capacity`)
- `meta.signed` / `meta.executionSubmitted` / `data.signed` / `data.submitted`
  are always `false`

MCP: `canix_simulate_execution`. See
`protocol/docs/execution-shapes/simulate-expected-delta.md`.

### Attached on `POST /plans`

When a plan (or rebalance) compiles unsigned groups, the same summary is
attached as `data.simulation`. Paying for the plan does not execute it.

## Agent loop

1. `POST /plans` / `canix_get_plan` (or quotes)
2. Review `data.simulation` or call `POST /execution/simulate` / `canix_simulate_execution`
3. If `wouldSucceed` is false, do not sign. Publish `reasons[]`.
4. Sign only user legs. Submit locally before `expiresAt`.
