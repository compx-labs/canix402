# WebMCP: in-page tools and prepaid session checkout

**Date:** 28 August 2026

Protocol **1.6.1**. The same MCP tools agents already discover remotely now register in-page at `/webmcp` (Canix402 Live). Humans buy one prepaid session with Pera or Defly; in-browser agents call the live Caddy gateway. Canix still never holds keys or submits transactions.

## What shipped

### `/webmcp` — Canix402 Live

A public page on `canix402.compx.io` that registers the locked live MCP set plus the 1.6.0 session tools via the WebMCP imperative API: `document.modelContext.registerTool`, with `navigator.modelContext` as the deprecated Chrome 150 / ChatGPT-preview alias.

- **21 tools.** Opportunity tools (`canix_list_opportunities`, `canix_search_opportunities`, `canix_get_personalized_opportunities`, `canix_get_protocol_opportunities`) fill the table. Wallet, plan, quote, swap, discovery, and session tools run from a slide-out (desktop) / slide-up (mobile) drawer.
- `execute` hits the live gateway and fails closed with machine-readable JSON: `PAYMENT_REQUIRED`, `SESSION_*`, `UNKNOWN_TOOL`, `INVALID_ARGUMENT`, `GATEWAY_CLIENT_ERROR`.
- Paid tools accept `paymentSignature` (agents) or `sessionReceipt` (humans and session-eligible agents). If `paymentSignature` is set, the page omits `X-Canix-Session` so a stale receipt cannot swallow a paid retry.
- Registration badges: **Registered** when the host API is present, **Catalog only** when it is not, **Failed** when `registerTool` throws. Humans can still run tools from the drawer either way.
- Origin isolation is required. The page never assigns `document.domain`. Production needs `Permissions-Policy: tools=(self), document-domain=()` and `Origin-Agent-Cluster: ?1` on `/webmcp*`.
- Local Chrome: enable `chrome://flags/#enable-webmcp-testing`.

This page does **not** invent a second session model. Receipts are the 1.6.0 `csess_` / `canix://session/{sessionId}` contract. Rebalance, simulate, compose, and policy-validate stay on remote MCP / HTTP for this ship.

Header link: **Canix402 Live**. Homepage CTA: **Try it now**.

### Human checkout (Pera / Defly)

Humans on this page do not spray per-request USDC. Connect a wallet, pay once, then call paid tools against the stored receipt.

- Wallet is **checkout only**. Pera or Defly signs the 0.25 USDC exact-scheme group that mints or refreshes the session. The wallet is not used to sign DeFi enter/exit groups.
- Create/refresh preflight without payment, then retry with a locally assembled `PAYMENT-SIGNATURE`. Failed settlement is `PAYMENT_FAILED`; wallet reject is `PAYMENT_REJECTED`.
- Receipt lives in `localStorage` (`canix402.webmcp.session`). Remaining research / quotes and expiry paint in the session bar. `canix_get_session` polls remaining N/M.
- Drawer forms for `canix_create_session` / `canix_refresh_session` return `HUMAN_CHECKOUT_REQUIRED`. Paid tools that are not session-eligible return `SESSION_REQUIRED`.
- NFD lookup labels the connected address when a name exists.

Sessions are receipts, not keys. Canix still never holds keys or submits transactions.

### In-browser agents

When a WebMCP host is present, the same 21 tools are callable from the page. Agents that can pay per request still use `paymentSignature`. Agents that already hold a `csess_` receipt pass `sessionReceipt`. Execute is fail-closed; there is no silent retry and no invented tool names.

## Pricing

No new SKUs. Session checkout uses the 1.6.0 prices:

| Step | Route / tool | Price |
| --- | --- | --- |
| Prepaid session (create / refresh) | `POST /sessions`, `POST /sessions/refresh` / `canix_create_session`, `canix_refresh_session` | **0.25 USDC** |
| Session receipt | `GET /sessions/:sessionId` / `canix_get_session` | **free** |
| Opportunity list / search / protocol | `GET /opportunities*` / `canix_list_opportunities`, `canix_search_opportunities`, `canix_get_protocol_opportunities` | **0.01 USDC** |
| Personalized opportunities | `GET /opportunities/personalized` / `canix_get_personalized_opportunities` | **0.05 USDC** |
| Plan compiler | `POST /plans` / `canix_get_plan` | **0.25 USDC** |

Humans on `/webmcp` pay the session SKU once (or refresh) and consume N research / M quotes for the TTL. Defaults remain **50** research, **10** quotes/plans, **4 hour** TTL.

## Human loop

1. Open https://canix402.compx.io/webmcp. Connect Pera or Defly.
2. Buy session (0.25 USDC). Confirm remaining research / quotes in the bar.
3. **Get top 25**, or open Tools and run `canix_search_opportunities` / `canix_get_personalized_opportunities`. Results replace the table.
4. Optional: eligibility, positions, claim desk, or `canix_get_plan` from the drawer. Review unsigned groups locally. Do not treat this page as a signer or submitter.
5. On `SESSION_EXPIRED` / `SESSION_EXHAUSTED`, Refresh or buy a new session. Do not fall back to per-request USDC on this page.

## Agent loop (WebMCP host)

1. Load `/webmcp` in a host with `document.modelContext` (or `navigator.modelContext`). Confirm tools show **Registered**.
2. Optional `canix_create_session` with `paymentSignature`, then pass `sessionReceipt` on research and quote tools.
3. Or call paid tools without payment, read `PAYMENT_REQUIRED`, retry with `paymentSignature`.
4. On `SESSION_EXPIRED` / `SESSION_EXHAUSTED` / `SESSION_INVALID`, omit the session header and either refresh or pay per request.
5. Sign only user legs from compiled quotes/plans. Submit locally. Canix never holds keys.
